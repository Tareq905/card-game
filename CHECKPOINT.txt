TASK 5 — Update vite.config.js  [CRITICAL — Frontend থেকে Backend API call করতে হবে]
--------------------------------------------------------------------------------
WHY: Frontend http://localhost:5173 এ চলে, Backend http://localhost:8000 এ।
     Browser এ cross-origin request করলে CORS error আসতে পারে। তাই Vite-এর
     built-in dev proxy ব্যবহার করতে হবে।
     এই proxy config না থাকলে:
       - /api/auth/login → 404 error (backend reach হবে না)
       - /ws/game → WebSocket connect হবে না

WHAT TO WRITE in vite.config.js:
  import { defineConfig } from 'vite'
  import react from '@vitejs/plugin-react'

  export default defineConfig({
    plugins: [react()],
    server: {
      port: 5173,
      proxy: {
        '/api': {
          target: 'http://localhost:8000',
          changeOrigin: true,
        },
        '/ws': {
          target: 'ws://localhost:8000',
          ws: true,         ← এই line WebSocket proxy এর জন্য mandatory
          changeOrigin: true,
        }
      }
    }
  })

  NOTE: '/ws' key দিয়ে WebSocket proxy করলে browser-এ ws://localhost:5173/ws/game
        হিসেবে connect করলেই হবে। GameContext.jsx এ ইতিমধ্যে সেভাবেই লেখা আছে।

KEY DESIGN DECISIONS (do not change these in future steps)
============================================================
- Auth: JWT tokens, stored in localStorage, sent as "Authorization: Bearer <token>" header
- WebSocket URL: ws://localhost:5173/ws/game?token=<jwt>  ← Vite proxy করে 8000 এ পাঠায়
- Redis: fakeredis in-memory (no external Redis process needed)
- Game state: stored in Redis as JSON under key "game:{game_id}"
- Matchmaking queue: Redis sorted set "matchmaking_queue" (score = timestamp)
  → 4 players হলে তাৎক্ষণিক match
  → 2-3 players + 5 seconds wait হলে match (timeout fallback)
- Pub/Sub channel: "game_channel:{game_id}" for broadcasting state updates
- Asset URLs: /assets/cards/back/{color}-{value}.png (served by Vite from public/)
- DB: PostgreSQL, tables: users, matches
- Token grant: 200 tokens on signup (display only, no economy logic yet — Step 2)
- Private rooms: REST-polled lobby (every 2s) + WS start notification
- Card naming convention: {color}-{value}.png e.g. red-5.png, blue-draw2.png, wild.png
- Turn timeout: 25 seconds → auto draw + skip. After 2 warnings → forfeit
- Disconnect grace period: 30 seconds → after that opponent wins
- "One Left" mechanic: yell before opponent catches → no penalty. Caught without yelling → draw 2
